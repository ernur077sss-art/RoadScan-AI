# Локальная разработка и запуск

Подробные команды для разработчика и оператора. [Вернуться к обзору проекта](../README.md).

Для публикации используйте [инструкцию Vercel](DEPLOY_VERCEL.md): веб из `web/`, отдельный контейнер API и постоянные PostgreSQL/S3.

## Быстрый локальный запуск

Требования: Python 3.12, Node.js 24, pnpm 11.25.0. Команды выполняются из корня репозитория. База и медиа создаются в `.data/`, в Git не попадают. У приложения нет предзаполненных дефектов, показателей или сотрудников.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
pnpm --dir web install --frozen-lockfile
.venv/bin/python -m alembic upgrade head
.venv/bin/python -m uvicorn api.main:app --host 127.0.0.1 --port 8000 --no-access-log --no-proxy-headers
```

Во втором терминале:

```sh
pnpm --dir web dev
```

Откройте **http://localhost:3000**. Для входа используйте синтетический номер формата `+77010000001`, примите условия и нажмите «Получить код». В локальной версии код отображается в форме; SMS не отправляется. Браузер должен открывать именно `localhost`, поскольку Origin проверяется строго.

Для просмотра production-сборки вместо dev-сервера: `pnpm --dir web build`, затем `pnpm --dir web start`. Скрипт добавит публичные ресурсы в standalone-папку и запустит веб-сервер на 127.0.0.1. API запускается отдельно.

`.env.example` документирует переменные. По умолчанию локальный режим работает без `.env`. Python CLI не читает этот файл автоматически: переменные нужно передать окружению процесса. Не публикуйте локальный режим в интернет.

## Выдача доступа инспектору

Сначала войдите по другому тестовому номеру в отдельном профиле браузера. Затем оператор на сервере выполняет:

```sh
.venv/bin/python -m api.manage grant-role --phone +77010000002 --role inspector
```

Обновите страницу: появится раздел «Инспектор». Регистрация всегда создаёт жителя. Переключателя ролей в приложении нет. CLI и защищённый API администратора сохраняют изменение роли в истории.

## PostgreSQL/PostGIS в Docker

```sh
docker compose up --build
```

Compose поднимает PostGIS, API, очередь и веб-приложение. Порты доступны только на localhost. Это **локальная** конфигурация с тестовыми SMS и файловым хранилищем. Docker/PostGIS-контур подготовлен, но на текущем компьютере Docker отсутствует; его запуск не заявлен как проверенный.

Продакшен требует отдельного контура HTTPS + PostgreSQL/PostGIS + private S3 + SMS-провайдера. Параметр `ROADSCAN_ENV=production` запрещает тестовый OTP, симулятор 109, SQLite и локальное медиахранилище.

## Проверки

```sh
.venv/bin/python -m pytest -q
.venv/bin/python -m scripts.check_brand
pnpm --dir web typecheck
pnpm --dir web build
pnpm --dir web test:e2e
```

Playwright сам запускает изолированный API на 8100 и Next.js на 3100. На macOS использует установленный Google Chrome; иначе сначала выполните `pnpm --dir web exec playwright install chromium`. При нестандартном пути Python передайте `ROADSCAN_PYTHON`. Тесты используют синтетические данные и отдельную папку `.data/e2e-*`.

Для PostgreSQL тесты используют `ROADSCAN_TEST_DATABASE_URL` и **пересоздают все таблицы**. Передавайте только адрес отдельной тестовой БД. Для такой проверки настроен GitHub Actions. Актуальные результаты доступны в [журнале CI](https://github.com/ernur077sss-art/RoadScan-AI/actions/workflows/ci.yml).

## Резервная копия локальной версии

```sh
.venv/bin/python -m api.backup --destination .data/backups/first
.venv/bin/python -m api.backup --verify .data/backups/first
```

Каталог назначения должен быть новым. Копия включает базу, медиа и ключ расшифровки телефонов: храните её в закрытом месте. Проверка не перезаписывает рабочую базу. Для PostgreSQL/S3 используйте регламент эксплуатации.

## Оформление

Выбраны «Зелёный квартал», Inter + JetBrains Mono и ровные цвета без градиентов. Шрифты включены в сборку. Светлая и тёмная темы используют общие семантические токены. Превью вариантов сохранены в `.brand-preview/`; после согласования их можно удалить. Резервная копия исходной темы — `web/app/globals.css.bak` (локальный файл, не коммитится).
