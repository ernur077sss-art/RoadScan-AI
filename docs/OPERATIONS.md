# Этап 8: эксплуатация и границы пилота

## Локальная разработка
SQLite + закрытая файловая папка поддерживаются исключительно для локального запуска и быстрых тестов. Рабочий контур: PostgreSQL/PostGIS + приватный S3 bucket. Docker Compose описывает локальный PostgreSQL-контур, не готовую публичную инфраструктуру.

## Перед внешним пилотом
- Определить оператора данных, разместить базу, медиа и резервные копии в Казахстане, согласовать текст согласия, сроки хранения и процесс удаления/отзыва. Заменить демонстрационный текст /privacy сведениями реального оператора.
- Настроить HTTPS, ROADSCAN_ENV=production, ROADSCAN_ORIGIN, случайный ROADSCAN_SECRET (32+ символов), PostgreSQL, приватное S3 и ROADSCAN_AUTH_MODE=password. SMS не требуется. Изолировать базу и хранилище от публичной сети.
- Выдать инспекторам роли через операторскую CLI, усилить доступ сотрудников согласно правилам заказчика. ИИН и документы не собирать.
- Ограничить размер тела на reverse proxy 26 MB, число соединений/частоту по IP; приложение ограничивает загрузки и SMS по пользователю/номеру. Перед приложением не доверять произвольному X-Forwarded-For. Сейчас SMS-IP учитывает прямой адрес соединения; для proxy нужен доверенный слой rate limiting.
- Замерить число ожидаемых пользователей и размер медиа, настроить квоты диска, мониторинг очереди и ошибок. Обработка видео синхронная, ограниченная 30 сек / 25 MB / 4K; массовый трафик потребует изолированного медиа-worker с квотами CPU.
- Проверить реальные Android/iPhone, регистрацию/вход, сессии, разрешения, фотосъёмку и плохую связь. Эмуляция браузера не заменяет испытания на устройствах. HEIC пока не поддерживается, используйте JPEG/PNG/WebP.
- Подключить собственную/лицензированную подложку карты для предполагаемого трафика. OSM-подложка в локальном демо онлайн; кэширование тайлов для offline не выполняется.

## Резервное копирование
Резервируется единый набор: PostgreSQL (pg_dump custom format), объектное хранилище с versioning и секрет ROADSCAN_SECRET в отдельном защищённом сейфе. Утрата секрета делает зашифрованные телефоны недоступными. Копировать SQLite-файл работающего сервера обычным cp нельзя: используйте sqlite backup API.

PostgreSQL: pg_dump --format=custom --file=roadscan.dump "$ROADSCAN_BACKUP_DSN". Восстанавливать через pg_restore в **отдельную пустую тестовую БД**. Затем сверить количество обращений, связи, чтение вложений и вход тестового пользователя. Не запускать restore на рабочей БД без отдельного разрешения.

S3: включить versioning, резервирование объектов в закрытое хранилище и lifecycle по согласованным срокам. Проверка только таблиц не подтверждает восстановление медиа.

## Обслуживание
`python -m api.worker --cleanup` удаляет только несвязанные загрузки старше 7 дней и истёкшие технические записи. Доказательства в обращениях не удаляет. Аварийно оставшиеся объекты без строки БД требуют сверки инвентаря и отдельного задания очистки; автоматическая массовая очистка не выполняется.

## Не выполнено автоматически
Покупка SMS/хостинга/домена, публикация, отправка данных в 109, сброс базы. Эти действия требуют подготовленного контура и согласования пользователя. Не публиковать development OTP наружу.


## Проверенная локальная процедура восстановления

`python -m api.backup --destination .data/backups/имя` создаёт согласованный снимок SQLite через backup API, копирует вложения, эффективный ключ и контрольные суммы. Каталог назначения должен отсутствовать. Права каталога — 0700, файлов — 0600. `python -m api.backup --verify .data/backups/имя` проверяет контрольные суммы, целостность базы, внешние ключи и наличие связанных вложений.

Автотест восстанавливает снимок в новый каталог и проверяет авторизованное чтение обращения и изображения. Он также намеренно повреждает копию изображения и проверяет обнаружение ошибки. Это подтверждает локальную процедуру; восстановление PostgreSQL/S3 проверяется отдельно на инфраструктуре пилота. При резервировании остановите очистку несвязанных загрузок; связанные доказательства не удаляются worker-ом.

Запуск Uvicorn использует `--no-proxy-headers`, чтобы клиент не подменял IP через X-Forwarded-For. При публикации настройте доверенный reverse proxy и ограничение запросов до Next.js. Нельзя просто включить доверие ко всем пересылаемым заголовкам.

## Бесплатный конкурсный стенд

[DEPLOY_FREE](DEPLOY_FREE.md) фиксирует лимиты и запрет платных услуг. Зарубежные бесплатные регионы не являются согласованным контуром для настоящего городского пилота: до согласования оператора используйте только синтетические номера и материалы. Supabase S3 не поддерживает versioning, поэтому приведённая выше стратегия версионирования требует отдельного внешнего резервирования. Восстановление облачной БД и файлов пока не проверено.
